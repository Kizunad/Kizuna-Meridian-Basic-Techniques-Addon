# 基础功法

纯数据 Fabric 模组，提供一本「基础功法」与三卷独立功法：调息、轻步、蓄力。
正式包无 Java 入口、类文件或 Mixin；玩家和类人宿主共用同一目录。
三式均提供目录显示名与完整使用说明，zh_cn/en_us 覆盖书名、卷名、式名和卷轴物品名。
学习后阅读页由功法库展示真实目录数值；空语言条目不再把式 ID 显示为名称。
